# FinMate 💰

A personal finance dashboard built with Flask — track transactions, budgets, savings goals, and investments with an AI advisor.

## Features

- 📊 **Dashboard** — Monthly income, expenses, savings overview
- 💳 **Transactions** — Add, categorize, and filter transactions
- 🏦 **Bank Connect** — Demo bank account integration
- 🎯 **Budgets** — Set and track category budgets
- 🏆 **Goals** — Savings goals with progress tracking
- 📈 **Investments** — Portfolio tracker with stocks & mutual funds
- 🤖 **AI Advisor** — Smart financial insights from your data

## Tech Stack

- **Backend**: Python / Flask
- **Frontend**: Vanilla JS, CSS3
- **Data**: In-memory store (demo mode)

## Running Locally

```bash
pip install -r requirements.txt
python app.py
```

Open [http://localhost:5000](http://localhost:5000)
deploy

The app can be deployed to any Python-compatible host (Render, Railway, Fly.io, etc.).

```bash
gunicorn app:app
```
